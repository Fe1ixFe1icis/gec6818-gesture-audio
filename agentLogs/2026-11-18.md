## 会话中段 · L2 · `sensor.c` 填实 PAJ7620U2 I2C 后端
- 操作：
  1. 删除占位 `i2c_probe()`（原实现只 `fopen("/dev/i2c-1")`）；
  2. 新增 `PAJ7620_*` 常量与 81 条上电+手势初始化表（数据手册/参考实现序列）；
  3. 新增 `paj_wr()` / `paj_rd()`：`I2C_RDWR` 组合传输，写寄存器地址后 repeated START 读，不发 STOP；
  4. 新增 `paj_open_bus()`：打开 `/dev/i2c-0..3`，只探 `0x73`（不做全总线扫描，避开 gslX680），
     读 `0x00==0x20` 判定在线，重试 3 次（首次 ACK 失败的兼容）；
  5. 新增 `paj_init_seq()`、`paj7620_open()`、`paj7620_gesture()`
     （0x43 bit0..5 → UP/DOWN/LEFT/RIGHT/PUSH/PULL，0x44 bit0 → HOVER；bit6/7 旋转不映射）；
  6. `sensor_init()` 改为探测成功才启用 I2C，否则 WARN 降级 sim；`sensor_finish()` 关闭 fd；
  7. 全部硬件路径用 `#if BOARD` 隔离，主机 `BOARD=0` 不编译 I2C 代码。
- 原因：M2-03；本板 `i2cget` 的 SMBus 读会 ack 失败，必须用组合读；`sensor.c` 原 I2C 分支
  只返回空手势。
- 影响文件：`src/sensor.c`（约 +160/−9 行）
- 可逆性：可直接撤销
- 结果：成功。主机 `gcc -DBOARD=0` 零警告；`--selftest` **19 通过 / 0 失败 / 1 跳过**。
