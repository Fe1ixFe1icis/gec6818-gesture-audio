# agentLogs — AI 操作留痕

存放 AI / Agent 在本仓库的所有操作记录，供组员事后审计对账。

**规范来源**：`AGENT.md §0.5 操作分级与 agentLogs 留痕（强制）`。本文件只做速查，冲突时以 `AGENT.md` 为准。

## 文件命名

`YYYY-MM-DD.md`，一天一个，**只追加**，不修改、不删除历史条目。

## 级别速查

| 级别 | 一句话 | 例子 | 什么时候写 |
|---|---|---|---|
| L0 | 只读，无副作用 | 读文件、搜索、查网页 | 可合并成一行 |
| L1 | 文档/注释变更 | 改 md、加注释 | 做完写一行 |
| L2 | 代码/构建配置变更 | 改 .c/.h、Makefile、.gitignore、建目录 | 做完写完整条目 |
| L3 | 破坏性/不可逆/批量 | 删文件、批量替换、覆盖大段内容 | **做之前写**，附回滚方式 |
| L4 | 外部副作用 | 任何 git 操作、push、发布、发消息 | 不执行，只登记"已给建议命令" |

## 单条格式

```
## HH:MM · L2 · 一句话标题
- 操作：做了什么，具体到文件与段落
- 原因：为什么做
- 影响文件：path（+X/-Y 行 或 新建/删除）
- 可逆性：可直接撤销 / 需备份恢复 / 不可逆
- 结果：成功 / 失败（附原因） / 部分完成
```

## 约定

- 失败、回滚、被打断的操作同样要留条目。
- 不同级别的操作不合并，按最高级别记录。
- 写日志本身不再生成日志（避免递归）。
- 不写明文密码、Token、私钥、内网 IP、组员联系方式。
- 本目录**纳入版本库**，与代码一起提交：让「板子上跑的程序 ↔ git 提交 ↔ 操作日志」三者可互相印证。
